# Local schema regressions

These are second-stage **local additions**, not ports from the Rust SDK workspace suite. They supplement the first test-only baseline (`0823ac1`) and assert desired behavior against the unchanged Go SDK (`09349ff`). They do not expect defects, skip failures, implement a decoder in fixtures, or depend on `.plan/` artifacts. Only public ACP types/constructors, JSON codecs, connections and transports are used.

```sh
GOPROXY=off GOSUMDB=off GOTOOLCHAIN=local \
  go test -mod=readonly -count=1 -timeout=30s ./conformance/regressions/schema
```

The tests are intentionally red before fixes. Successful controls keep omission, concrete values, boolean false, valid zeros/empty values, declared default-on-null arrays, empty summaries, and null-sensitive metadata distinct. Most cases are finite codec fixtures. One public delivery regression completes V1 initialize/new-session setup and independently checks typed callback visibility and raw outgoing params. It waits for each observation, not a prompt/load response barrier; raw stream deadlines, retained closers and buffered producers bound failure and shutdown.

Plain schema validation cannot detect a valid clear becoming a valid omission, implement annotated partial recovery, or check Go dynamic type identity. Expected values therefore come from literals and the documented contracts, not from the SDK's current output.

## External schema-crate provenance

Patch and extensible-action expectations are informed by the separately inventoried **`agent-client-protocol-schema` 1.15.1** (Apache-2.0), VCS `0fc18323a9fdad4e5b4a20ec2f1645dde843fd9b`, path `agent-client-protocol-schema`. Those dependency tests were deliberately excluded from the first SDK-workspace port commit; these local additions may use them as an independent expectation source:

- [`src/v1/client.rs::test_serialization_behavior`](https://github.com/agentclientprotocol/agent-client-protocol/blob/0fc18323a9fdad4e5b4a20ec2f1645dde843fd9b/agent-client-protocol-schema/src/v1/client.rs#L5285): session-info omission/null/value and explicit clear emission.
- [`CompactionUpdate`](https://github.com/agentclientprotocol/agent-client-protocol/blob/0fc18323a9fdad4e5b4a20ec2f1645dde843fd9b/agent-client-protocol-schema/src/v1/client.rs#L830) and its [patch control](https://github.com/agentclientprotocol/agent-client-protocol/blob/0fc18323a9fdad4e5b4a20ec2f1645dde843fd9b/agent-client-protocol-schema/src/v1/client.rs#L4427): three-state public model. The all-three-field fixtures here extend that control from the declared contract.
- [`unknown_action_response_serialization`](https://github.com/agentclientprotocol/agent-client-protocol/blob/0fc18323a9fdad4e5b4a20ec2f1645dde843fd9b/agent-client-protocol-schema/src/v1/elicitation.rs#L2298), [`unknown_action_does_not_hide_known_action`](https://github.com/agentclientprotocol/agent-client-protocol/blob/0fc18323a9fdad4e5b4a20ec2f1645dde843fd9b/agent-client-protocol-schema/src/v1/elicitation.rs#L2317), and [`OtherElicitationAction`](https://github.com/agentclientprotocol/agent-client-protocol/blob/0fc18323a9fdad4e5b4a20ec2f1645dde843fd9b/agent-client-protocol-schema/src/v1/elicitation.rs#L1946): raw unknown fields and known-tag exclusion. The `vendorData`, known-field-name and malformed-value fixtures here are local extensions, not claimed original SDK test cases.

The V1 action description **recommends** preserving unknown payloads for storage/replay/proxying and forbids treating them as known actions. These tests target SDK data fidelity; they do not claim every agent must execute, store or forward unknown vendor actions. `content` is variant-specific, unlike common `_meta`, whose recovery annotation still applies.

Malformed known accept content is structurally invalid and has no recovery annotation. Rejection here is the desired typed decoder contract, not a claim about validating application-specific form answers or requiring a particular JSON-RPC response from every ACP implementation. At the baseline, the bad-container control already rejects; the nested bad value is accepted as **known accept**, so that failure alone is not evidence of a literal catch-all fallthrough mechanism.
